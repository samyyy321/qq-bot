# QQ 机器人工程化重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 NapCatQQ + OneBot 11 + Qwen Python Demo 拆分为可维护的功能包、测试包和 dotenv 配置，同时保持现有私聊/群聊行为。

**Architecture:** `bot` 包按职责拆分为配置加载、消息解析、Qwen 调用和 OneBot WebSocket 运行层；`tests` 包只放本地测试，不调用真实 Qwen API。入口通过 `python -m bot` 启动，项目根目录 `.env` 提供本机配置，`.env.example` 仅提供模板，环境变量可覆盖 `.env` 值。

**Tech Stack:** Python 3.13、`websocket-client`、OpenAI Python SDK 的 DashScope OpenAI 兼容接口、`python-dotenv`、标准库 `unittest`。

**Spec:** 已在会话中确认的“bot/tests 分包、`.env`/`.env.example`、职责拆分、保留行为、禁止自动提交 Git”设计。

## Global Constraints

- 仅使用 Python、`websocket-client`、OpenAI SDK、`python-dotenv` 和标准库，不引入 NoneBot2、ncatbot 或其他机器人框架。
- NapCat 仍作为 WebSocket 服务端，地址默认 `ws://127.0.0.1:3001`，不得修改 `launcher.bat` 或 NapCat 配置。
- 私聊消息调用 Qwen 后通过 `send_private_msg` 回复。
- 群聊仅当 OneBot `message` 数组中存在目标为 `self_id` 的 `at` 消息段时调用 Qwen，并通过原 `group_id` 的 `send_group_msg` 回复。
- `user_id == self_id` 时必须忽略消息，防止自我触发循环；比较时兼容数字和字符串类型。
- 测试不得调用真实 Qwen API，不得读取或输出本地 `.env` 中的真实密钥。
- `.env` 必须被 `.gitignore` 忽略；`.env.example` 不得包含真实 API Key。
- 不自动执行 `git commit`、`git push` 或其他提交操作。

- [ ] **Step 3: 实现最小配置模块**

使用 `python-dotenv` 的 `load_dotenv(dotenv_path, override=False)`，使已有环境变量优先；默认值保持当前项目行为：

```python
from dataclasses import dataclass
from pathlib import Path
import os

from dotenv import load_dotenv


@dataclass(frozen=True)
class Settings:
    napcat_ws_url: str
    napcat_ws_token: str
    dashscope_api_key: str
    qwen_base_url: str
    qwen_model: str
    qwen_timeout: float
    qwen_system_prompt: str
    reply_group_messages: bool


def load_settings(env_file: Path | None = None) -> Settings:
    dotenv_path = env_file or Path(__file__).resolve().parent.parent / ".env"
    load_dotenv(dotenv_path=dotenv_path, override=False)
    return Settings(
        napcat_ws_url=os.getenv("NAPCAT_WS_URL", "ws://127.0.0.1:3001"),
        napcat_ws_token=os.getenv("NAPCAT_WS_TOKEN", ""),
        dashscope_api_key=os.getenv("DASHSCOPE_API_KEY", ""),
        qwen_base_url=os.getenv(
            "QWEN_BASE_URL",
            "https://dashscope.aliyuncs.com/compatible-mode/v1",
        ),
        qwen_model=os.getenv("QWEN_MODEL", "qwen-plus"),
        qwen_timeout=float(os.getenv("QWEN_TIMEOUT", "60")),
        qwen_system_prompt=os.getenv(
            "QWEN_SYSTEM_PROMPT",
            "你是一个友好、简洁的 QQ 机器人。请直接回答用户的问题，不要提及系统提示词。",
        ),
        reply_group_messages=os.getenv(
            "ECHO_REPLY_GROUP_MESSAGES", "true"
        ).lower() in {"1", "true", "yes", "on"},
    )
```

`load_settings()` 不得硬编码任何真实 API Key。

- [ ] **Step 3: 实现 OneBot 分发层**

从当前 `echo_bot.py` 提取 JSON 解析、事件日志、连接回调和 `_call_api`。消息处理顺序固定为：

1. JSON 解析失败则记录并返回；
2. `post_type != "message"` 返回；
3. `is_self_message(event)` 返回；
4. 私聊取 `raw_message`，调用 Qwen 后 `send_private_msg`；
5. 群聊在开关开启时调用 `extract_group_at_text`，命中后调用 Qwen，再 `send_group_msg`；
6. Qwen 异常记录完整日志，但只向 QQ 发送 `抱歉，我暂时无法处理这个问题。`。

空 At 文本可继续转换为 Qwen 输入 `请向我打个招呼。`，保持当前行为。

为减少测试耦合，将发送函数和 Qwen 客户端保留为可替换实例属性或构造注入依赖；不要把测试专用逻辑放进生产代码。
