# QQ 机器人定时群提醒实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有 NapCatQQ + OneBot 11 + Qwen 机器人增加按北京时间运行、仅向配置群号发送的早间、喝水和晚间定时提醒。

**Architecture:** 使用标准库后台线程实现轻量调度，不引入 APScheduler。`ReminderService` 负责生成三类提醒并向配置群发送，`ReminderScheduler` 负责时区时间匹配和当天任务去重；主线程继续运行 OneBot WebSocket，入口负责组装并启动后台调度器。

**Tech Stack:** Python 3.13、标准库 `threading`/`datetime`/`zoneinfo`、现有 `websocket-client`、OpenAI Python SDK 的 Qwen 兼容接口、`python-dotenv`、标准库 `unittest`。

**Spec:** [docs/superpowers/specs/spec_20260905_092050_定时群提醒.md](../specs/spec_20260905_092050_定时群提醒.md)

## Global Constraints

- 仅使用 Python、现有依赖和标准库，不引入 APScheduler、NoneBot2、ncatbot 或其他复杂框架。
- NapCat 仍作为 `ws://127.0.0.1:3001` 的 WebSocket 服务端，不修改 NapCat 配置和 `launcher.bat`。
- 所有定时提醒只发送到 `REMINDER_GROUP_IDS` 解析出的群号，不查询或匹配群名。
- 定时器统一使用 `REMINDER_TIMEZONE=Asia/Shanghai`，默认北京时间。
- 09:00 早间提醒和 21:00 晚间提醒调用 Qwen；11:00、13:00、15:00、17:00、19:00 喝水提醒使用固定文本，不调用 Qwen。
- 机器人启动后不补发已经错过的任务；只匹配当前时区的当前分钟。
- 机器人自身消息必须继续过滤，群聊普通消息和 @其他成员不得触发 Qwen。
- 测试不得调用真实 Qwen API、真实天气 API 或真实 NapCat WebSocket。
- `.env` 不得进入 Git；不得把 API Key 写入代码、模板、测试、日志或文档。
- 不执行 `git add`、`git commit` 或 `git push`。

- [ ] **Step 3: 实现调度器**

任务映射使用：

```python
{
    settings.reminder_morning_time: "morning",
    **{water_time: "water" for water_time in settings.reminder_water_times},
    settings.reminder_night_time: "night",
}
```

任务去重键必须包含本地日期和任务时间/类型，例如：

```text
2026-09-05:morning
2026-09-05:water:11:00
2026-09-05:night
```

`check_once()` 只比较 `now.strftime("%H:%M")` 与任务时间；命中后先加入当天已执行集合，再调用服务，确保同一分钟不会重复。跨日期时清理旧日期键，进程重启时集合为空，因此不会补发。

循环使用 `threading.Event.wait(check_interval)`，而不是不可中断的 `sleep`。`start()` 重复调用不得创建多个线程；`stop()` 可重复调用。后台循环捕获并记录异常，单次异常不能让整个线程静默退出。
